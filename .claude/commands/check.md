description: 모든 HTML 파일의 제목, 깨진 링크, 콘솔 에러를 점검하고 통과/수정 필요 표로 보고
---

이 프로젝트의 모든 `.html` 파일을 대상으로 다음을 점검하라:

1. **제목(title)**: 각 페이지에 `<title>` 태그가 있는지, 내용이 비어있지 않은지 확인
2. **깨진 링크**: `<a href>`, `<img src>`, `<link href>`, `<script src>` 등이 가리키는 로컬 파일 경로가 실제로 존재하는지 확인 (외부 URL은 형식만 확인)
3. **콘솔 에러**: 가능하면 브라우저(Claude in Chrome)로 각 페이지를 열어 콘솔 에러/경고를 확인. 브라우저 확인이 불가능하면 정적 분석(예: 정의되지 않은 함수 참조, 문법 오류 가능성)으로 대체하고 그 사실을 명시

점검이 끝나면 결과를 파일별로 아래와 같은 표로 정리해서 보고하라:

| 파일 | 제목 | 깨진 링크 | 콘솔 에러 | 상태 |
|---|---|---|---|---|
| ... | ... | ... | ... | 통과 / 수정 필요 |

- "상태" 열은 문제가 하나라도 있으면 "수정 필요", 없으면 "통과"로 표기
- "수정 필요" 항목은 표 아래에 구체적인 문제 내용과 위치(파일:줄)를 덧붙여 설명
- 코드를 임의로 수정하지 말고 점검 결과만 보고할 것 (수정은 별도 요청 시 진행)
